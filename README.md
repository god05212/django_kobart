# News Summary Web Application
## 뉴스 요약 웹 애플리케이션
프로젝트 기간: 2024/09/09(월) ~ 2024/09/27(금)  
## 개요
이 프로젝트는 ‘네이버 뉴스’ 사이트의 정보를 활용하여 사용자가 입력한 검색어에 따라 관련 뉴스 기사를 수집, 요약하고, 요약된 내용에서 **주요 키워드를 분석해 추천 검색어와 워드클라우드를 제공**하며, 나아가 **Stable Diffusion 기반의 이미지 생성까지 시도한 웹 기반 뉴스 요약 시스템**입니다.

정보 과잉 시대에서, 사용자가 신속하게 핵심 뉴스를 파악하고, 시각적으로도 내용을 직관적으로 이해할 수 있도록 하기 위해 본 프로젝트를 기획하였습니다.

**프로젝트 목표**
- **데이터 수집**: BeautifulSoup을 사용하여 네이버 뉴스에서 실시간으로 기사를 수집합니다.
- **기사 요약**: KoBART 모델을 활용하여 뉴스 본문을 간결하게 요약합니다.
- **명사 추출 및 검색어 추천**: 요약된 본문에서 명사를 추출하여 가장 많이 등장한 키워드를 기반으로 연관 검색어를 추천합니다.
- **워드클라우드 시각화**: 요약된 내용의 핵심 키워드를 시각적으로 표현하여 사용자의 이해를 돕습니다.
- **Stable Diffusion 이미지 생성**: 사용자의 검색어를 기반으로 해당 주제를 시각화한 AI 이미지를 생성합니다.
- **사용자 친화형 UI/UX**: 음성 입력, 실시간 로딩, 추천 키워드 등의 인터페이스로 사용자 경험을 향상시킵니다.  

이 프로젝트를 통해 사용자는 원하는 뉴스 기사를 보다 효율적으로 찾을 수 있으며, 기업은 뉴스 소비 트렌드를 이해하는 통찰을 얻고 향후 고객 맞춤형 서비스 개발에 기여할 수 있습니다.
<br/>

## 프로젝트 수행 과정
### 1. 모델 로드 및 데이터 처리
#### 1.1 KoBART 모델 및 토크나이저 로드
- **작업 설명**: `transformers` 라이브러리를 활용하여 KoBART 모델과 토크나이저를 불러오는 작업을 수행.
- **구현 과정**:  
  - `PreTrainedTokenizerFast`와 `BartForConditionalGeneration` 클래스를 통해 사전 학습된 요약 모델을 로드.  
  - GPU 사용 환경을 구성하여 모델 추론 속도를 최적화.
#### 1.2 불용어 리스트 정의
- **작업 설명**: 명사 추출 후 의미 없는 단어를 제거하기 위한 불용어 리스트를 구축.
- **구현 과정**:  
  - 한국어 불용어를 수집하여 리스트 형태로 저장.  
  - 이후 명사 추출 단계에서 필터링 기준으로 활용.

### 2. 기능 구현
#### 2.1 POST 요청 처리 및 응답 생성 (first_view)
- **작업 설명**: 사용자의 검색어를 서버에 전달하고 요약 프로세스를 시작하는 기능을 구현.
- **구현 과정**:  
  - Django 뷰 함수에서 `POST` 요청 시 `news_summary` 함수를 호출하여 데이터 처리 수행.  
  - `GET` 요청 시 기본 검색 페이지를 렌더링.
#### 2.2 뉴스 기사 크롤링
##### 2.2.1 Naver 뉴스 검색 API 활용
- **작업 설명**: 검색어 기반으로 네이버 뉴스 API에서 데이터를 요청.
- **구현 과정**:  
  - `requests`를 이용해 API에 `GET` 요청을 전송.  
  - HTTP 응답 상태를 확인하고 예외 처리를 구현.
##### 2.2.2 기사 정보 추출 및 구조화
- **작업 설명**: 응답 데이터에서 뉴스 제목, 링크, 본문을 정제하고 구조화.
- **구현 과정**:  
  - `BeautifulSoup`로 HTML을 파싱하여 필요한 정보를 추출.  
  - 각 항목을 리스트 형태로 저장.
###### 2.2.2.1 기사 제목
- **작업 설명**: 기사 제목을 파싱하여 저장.
- **구현 과정**:  
  - `.find()` 메서드를 이용해 제목 추출 후 공백 제거.
###### 2.2.2.2 기사 링크
- **작업 설명**: 기사 상세 페이지의 링크를 수집.
- **구현 과정**:  
  - `href` 속성을 가져와 링크 정보로 저장.
###### 2.2.2.3 기사 본문 내용
- **작업 설명**: 기사 상세 내용을 수집.
- **구현 과정**:  
  - 본문이 없을 경우 "본문 없음"으로 처리하여 누락 방지.
#### 2.3 본문 요약 생성 (summarize_texts)
- **작업 설명**: 크롤링한 기사 본문을 요약하는 기능 구현.
- **구현 과정**:  
  - KoBART 모델을 활용하여 요약된 결과를 리스트로 저장.
#### 2.4 명사 추출 및 빈도수 계산 (extract_nouns)
- **작업 설명**: 요약된 텍스트에서 핵심 명사를 추출하고 빈도수 분석 수행.
- **구현 과정**:  
  - `Okt` 형태소 분석기로 명사를 추출하고 불용어를 제거.  
  - `Counter`를 사용해 명사 출현 빈도를 계산.
#### 2.5 빈도수 높은 명사 10개 선정
- **작업 설명**: 사용자에게 추천할 주요 키워드 10개를 도출.
- **구현 과정**:  
  - `Counter.most_common()` 메서드를 활용해 상위 10개 명사를 선정.
#### 2.6 워드클라우드 시각화 (코드 구현)
- **작업 설명**: 명사 빈도수를 시각화하여 정보 전달력을 강화.
- **구현 과정**:  
  - `WordCloud` 라이브러리를 사용하여 이미지 생성 코드를 구현.  
  - 현재는 웹에 연결되지 않았지만, 이미지 저장 및 추후 템플릿 연동 가능.
#### 2.7 Stable Diffusion 이미지 생성 (코드 구현)
- **작업 설명**: 검색어 기반의 AI 이미지 생성 기능을 구현.
- **구현 과정**:  
  - Hugging Face의 `StableDiffusionPipeline`을 활용해 텍스트 기반 이미지 생성.  
  - 생성된 이미지는 로컬에 저장되며 향후 웹 인터페이스에 연동 가능.

### 3. 사용자 인터페이스 설계
#### 3.1 검색창 및 음성 입력 버튼 구성
- **작업 설명**: 검색 기능과 음성 입력 기능을 위한 UI 요소 구현.
- **구현 과정**:  
  - HTML과 CSS로 입력창 및 마이크 버튼 설계.  
  - 사용자 경험을 고려해 직관적 인터페이스 구성.
#### 3.2 결과 표시 및 로딩 인디케이터 구현
- **작업 설명**: 결과가 출력되기 전 로딩 상태를 시각적으로 표시.
- **구현 과정**:  
  - JavaScript를 활용하여 로딩 인디케이터를 비동기 처리에 적용.
#### 3.3 검색 결과 페이지 구성
##### 3.3.1 기사 목록 출력 및 포맷 설정
- **작업 설명**: 수집한 기사 목록을 사용자에게 보기 좋게 출력.
- **구현 과정**:  
  - Django 템플릿을 사용해 기사 제목, 링크, 요약문을 리스트 형태로 출력.
##### 3.3.2 추천 검색어 목록 제공
- **작업 설명**: 사용자의 검색어와 관련된 주요 명사를 추천 키워드로 제공.
- **구현 과정**:  
  - 명사 빈도 정보를 기반으로 상위 10개 키워드를 화면에 출력.
##### 3.3.3 재검색 링크 제공
- **작업 설명**: 사용자가 쉽게 다른 키워드로 검색할 수 있도록 유도.
- **구현 과정**:  
  - Django 템플릿 태그를 활용하여 재검색 링크를 생성.

### 4. 음성 인식 기능 통합
#### 4.1 SpeechRecognition API 사용 및 설정
- **작업 설명**: 웹에서 한국어 음성 인식을 위한 API 설정.
- **구현 과정**:  
  - SpeechRecognition API에서 언어를 `ko-KR`로 설정.
#### 4.2 음성 인식 결과 자동 입력 처리
- **작업 설명**: 인식된 음성을 텍스트 입력창에 자동 반영.
- **구현 과정**:  
  - 인식 결과를 검색창에 자동 삽입하여 편의성을 높임.

## 사용한 KoBART 모델 및 Tokenizer
- **참조 데이터**: AIHUB에서 제공하는 문서 요약 데이터셋을 활용. (https://aihub.or.kr/aidata/8054)
- **데이터 생성**: 데이터셋을 기반으로 임의로 Train 및 Test 데이터를 생성.
- **형식**: 데이터는 TSV(Tab-Separated Values) 형식으로 변환하여 탐색 용이성을 극대화.
- **데이터 구조** 
  - Train 데이터: 34,242개로 구성.
  - Test 데이터: 8,501개로 구성.
- **Tokenizer**: 모델 학습에 사용된 토크나이저는 **PreTrainedTokenizerFast.from_pretrained('digit82/kobart-summarization')** 로, KoBART 모델에 최적화된 토크나이징 기능을 제공.
- **모델 초기화**: KoBART 모델은 **BartForConditionalGeneration.from_pretrained('digit82/kobart-summarization')** 를 통해 사전 학습된 가중치로 초기화하여 문서 요약 작업에 적합하도록 설정.

- **음성 입력 기능**: 사용자가 음성으로 검색 가능.
- **자동 요약**: 기사 본문을 자동으로 요약하여 제공.
- **명사 분석**: 검색 결과에서 빈도 높은 명사 추출 및 추천.
- **직관적인 디자인**: 사용자 친화적인 인터페이스와 배경 이미지.
- **실시간 로딩 표시**: 검색 중 진행 상황을 시각적으로 안내.
